# 啟動翻譯器.bat 顯示的中文訊息（UTF-8）。cmd 執行含中文的批次檔時，跳轉後常把中文行切壞，
# 所以批次檔本身只用 ASCII，訊息都放在這裡，格式為「代號=訊息」。
CONDA_FOUND=使用的 conda：
CONDA_SETUP=建立 conda 環境「merc-storia」（Python 3.12，需要網路，約幾分鐘）…
VENV_SETUP=第一次執行：建立 Python 環境（需要 Python 3.10 以上）…
DEPS=安裝需要的套件…
USING=使用的 Python：
NO_PY1=找不到 conda 或 Python 3.10 以上版本。建議安裝 Miniconda：https://www.anaconda.com/download/success
